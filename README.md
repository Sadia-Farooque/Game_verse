# GameVerse

A responsive, dark-first discovery homepage for free browser games, built with React and Vite. The experience includes game search and category filters, a favorites list, theme switching, responsive navigation, and transparent preview dialogs for the sample games.

## Run locally

```sh
npm install
npm run dev
```

## Build for deployment

```sh
npm run build
npm run preview
```

The production-ready site is generated in `dist/`. Game names, ratings, categories, and images are sample content; real game play and account services are not connected yet.
